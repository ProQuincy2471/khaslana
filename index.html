This tab

Khaslana never navigates — Dawn, Atlas, Setup are all one page switched by JS, so a tab left open just keeps running whatever loaded it. This checks every 90 seconds for a newer build and offers to reload; it never does it on its own, in case you're mid-sentence in the Chronicle.
Build loaded in this tab: —
Reload asks for what's new but still trusts what this device already saved offline — the service worker's own cache. Almost always right. When it's wrong (a bad file cached before you'd logged in, from behind Access, is the one way this has actually happened), no amount of reloading fixes it, because reloading is exactly the thing serving the bad copy. This forgets everything this device saved for offline use and re-downloads it clean — the fix that used to mean deleting the app and reinstalling it.

Sync

The phone and the Mac share one state through this GitHub repo — no separate server. Needs a token this device keeps to itself: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → scope it to just this one repo, permission "Contents: Read and write". Paste it below with the repo as owner/name. Do this on every device you want synced.
Not connected.
The token field above shows blank every time you open this — on every device, always, even while connected. It's never written back in once saved, so there's nothing to display. The line just above this one is the real answer: if it says "Connected to…", nothing needs re-entering.
Autosync waits — up to a minute, or until this tab goes to the background — so ticking a task doesn't write a commit for every keystroke. This skips the wait: pulls whatever's on GitHub first, then pushes whatever's still only here. The same button lives in the rail, under Search, on every screen — this one's just the version with a full explanation next to it.
